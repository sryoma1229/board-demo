# board-demo

PHPとMySQLを使用した掲示板Webアプリケーションです。

## Setup
1. `composer install` を実行します。
2. MySQLでデータベース(例: `board`)を作成し、`schema.sql` をインポートします。
3. `config/db.php` を自分の環境のDB情報に書き換えます。
